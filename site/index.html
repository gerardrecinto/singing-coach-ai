How it works

1recording or video→2ffmpeg (video only)→3librosa analysis→4JSON report→5Claude prompt→6coaching text
1

Measure

Pitch by pyin: stability, mean note, range, drift. Rhythm: tempo, beat count, regularity. Dynamics: average and peak level, range, consistency. Tone: spectral centroid and MFCC.

2

Report

The numbers become one JSON report. With --no-ai that is the whole output and no network call is made.

3

Coach

The report goes to Claude in a prompt that asks for direct, specific feedback in Pitch, Rhythm and Dynamics sections, plus two or three things to practice.

Run it on a recording

Python 3.9 or later. ffmpeg is needed for video files only.

pip install -r requirements.txt
export ANTHROPIC_API_KEY=your-key

python singing_coach.py my_recording.mp3
python singing_coach.py practice.mp4
python singing_coach.py my_recording.mp3 --no-ai
brew install ffmpeg   # macOS
apt install ffmpeg    # Ubuntu or Debian

Formats: mp3, wav, flac, ogg, m4a, aac on the audio side, and mp4, mov, mkv, webm on the video side.

What this does not do
  • It does not run in the browser, so this page cannot analyze your voice.
  • Feedback comes from a language model reading numbers. It cannot hear you and it is not a substitute for a teacher.
  • Pitch tracking can misread noisy recordings, harmonies and heavy reverb.
  • Without --no-ai the report is sent to the Anthropic API, so do not use it for recordings you cannot share.
